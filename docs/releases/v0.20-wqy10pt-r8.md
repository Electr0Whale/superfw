# SuperFW WQY 10pt r8

## 中文

### 自 v0.20-wqy10pt-r3 以来的更新

- 为 ROM、最近游戏和 NOR 浏览器整合封面预览；封面尺寸、对齐和 16bpp BMP 颜色解释均已
  修正。
- 封面加载从 SD 卡上的分散缓存文件改为可选的 `/.superfw/covers.pak` 分页资源包。它使用
  离线量化和格式验证、按页索引及多扇区读取，降低浏览时的文件系统访问次数，并可从临时
  SD 读取错误恢复。
- 发布 2,915 条目的 GBA 封面包，增加已核验的中文 ROM 地区封面别名和 FICC 原型封面；
  头部游戏码无效的 ROM 不做错误匹配。
- “隐藏扩展名”设置现在持久保存，最近游戏列表显示 Flash 标识；NOR/最近游戏启动、Flash
  存档路径和游戏内菜单的“重置并加载存档”均得到改进。
- 整合上游非阻塞 Flash 擦除、并行 SDRAM 读取、压缩器和资源打包更新、翻译与补丁数据库
  更新，以及对应的测试改进。
- GitHub Actions 现在构建并发布经过验证的 SuperCard Chis 固件，同时附带封面包用法。为
  保持 WenQuanYi 扩展字体，Release 不发布无法容纳该字体包的 SD/Lite 固件。

### Release 资产

- `superfw-chis.fw`：已编译的 SuperCard Chis 固件。
- `superfw-covers.pak`：可选的预构建 GBA 封面包。
- `cover-pack-usage.md`：中英文封面包安装说明。

### 封面包安装

将 `superfw-covers.pak` 复制到 SD 卡根目录下的 `/.superfw/covers.pak`，然后重启掌机。
资源包缺失或损坏只会关闭封面显示，不影响游戏启动。

## English

### Changes since v0.20-wqy10pt-r3

- Integrate cover previews in ROM, recent-game, and NOR browsers, with fixes
  for cover dimensions, alignment, and 16bpp BMP color interpretation.
- Replace scattered SD-card cover cache files with the optional paged
  `/.superfw/covers.pak` resource. Offline quantization and format validation,
  paged indexing, multi-sector reads, and transient SD-read recovery reduce
  filesystem work while browsing.
- Publish a 2,915-entry GBA cover package with verified regional-cover aliases
  for compatible Chinese ROMs and the FICC prototype cover. ROMs with invalid
  header game codes are deliberately not mismatched.
- Persist the hide-extension setting, mark Flash titles in the recent list,
  and improve NOR/recent launching, Flash save paths, and the in-game menu's
  reset-and-load-save action.
- Integrate upstream non-blocking Flash erase, parallel SDRAM reads, compressor
  and resource-packaging updates, translation and patch-database updates, and
  associated test improvements.
- GitHub Actions now builds and publishes verified SuperCard Chis firmware with
  cover-pack instructions. To retain the extended WenQuanYi font, Releases do
  not publish SD/Lite firmware, whose ROM budgets cannot contain that font pack.

### Release assets

- `superfw-chis.fw`: compiled SuperCard Chis firmware.
- `superfw-covers.pak`: optional prebuilt GBA cover package.
- `cover-pack-usage.md`: bilingual cover-pack installation guide.

### Cover-package installation

Copy `superfw-covers.pak` to `/.superfw/covers.pak` at the SD-card root, then
restart the console. A missing or invalid resource only disables cover display;
it does not prevent games from launching.
